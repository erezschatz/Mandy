2. what to do, and what passes

  1. Type a few characters mid-word. Each one is a single insertText, the text appears, and divergence stays quiet.
  2. Select a word and type over it. One insertText whose target range is the selection.
  3. Backspace mid-word, then Delete (fn+Delete on a Mac). deleteContentBackward / deleteContentForward, each with a target range one character wide.
  4. Delete a word — Option+Backspace on a Mac, Ctrl+Backspace elsewhere. One deleteWordBackward whose range covers the whole word: the engine decides what a word is, and we do not.
  5. Backspace at the very start of a paragraph. The range should span two blocks. It is refused for now — nothing happens, no divergence — because a merge is slice 4's.
  6. Type an accented character — hold e on a Mac, or use a dead key. compositionstart, then the engine writes while we wait, then compositionend applies it as one edit.
  7. Type into the bold run, at its very end, and at its very start. The end continues bold; the start does not.
  8. Click on the equation itself and type a letter. The letter appears beside it and the equation survives — the range in the log is collapsed, n–n. This is the one Gecko found on 2026-09-20: a caret inside the span used to report 12–13 and the letter ate the equation.
  9. Drag across the whole equation to select it, then type. Now it is replaced, and the range in the log spans it, n–n+1. The pair is the point: one position is not a range.
  10. Click just after the image and type. The letter lands after it; the image survives. Then select the image — drag across it, or click it and use Shift+Arrow — and type: it is replaced. It is one character, the same as the equation.
  11. Press Enter, and Ctrl/Cmd+Z. Both are cancelled and do nothing — structure is slice 4, undo is slice 6. Nothing should move.
  12. Use the toolbar's formats — there is no toolbar here, so skip this one. In the app with ?core=model, the format bar does nothing on purpose: execCommand fires input but never beforeinput, measured in Chrome 152, so it cannot be intercepted and is refused rather than allowed to change the DOM behind the model's back. Formats arrive as model commands in slice 7.

Fail is any of: a character that does not appear, a caret that jumps, a divergence line that lights up, or an inputType reported as not cancelable.
