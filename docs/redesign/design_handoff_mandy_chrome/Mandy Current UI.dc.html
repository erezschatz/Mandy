Welcome to Mandy

A simple markdown editor that edits the files on your own machine. Start typing and see your formatted text in real-time!

Quick Start

Select text to see formatting options appear above it. Put the cursor at the start of a line and a shorter bar appears with the formats that act on the whole line — headings, lists and a code block.

  • File — Open… a markdown file from your machine, Save straight back to it, or Save As… somewhere new.
  • Edit — Undo and Redo, and Clear document, which empties the text but keeps the file you have open.
Your markdown data never leaves your device.
