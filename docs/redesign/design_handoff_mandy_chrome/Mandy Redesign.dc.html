Welcome to Mandy

A simple markdown editor that edits the files on your own machine. Start typing and see your formatted text in real-time.

Quick Start

Select text to see formatting options appear above it. Put the cursor at the start of a line and a shorter bar appears with the formats that act on the whole line — headings, lists and a code block.

  • File — Open… a markdown file from your machine, Save straight back to it, or Save As… somewhere new.
  • Edit — Undo and Redo, and Clear document, which empties the text but keeps the file you have open.
Your markdown data never leaves your device. Read why.

Running locally

The server serves the editor and gives it read/write access to your .md files.

npm run serve

The five moves
  1. The blue is gone. --accent-blue becomes teal; links, active formats, checkmarks and focus rings all read as one family.
  2. Header thinned to 40px. One row of 13px type; the open file's directory moves into it, and the theme toggle becomes a two-state sun/moon switch instead of an unlabelled pill.
  3. Tabs sit on the page. Real tab shapes on the page colour, the active one paper-white and flush with the sheet below — so a tab visibly holds the document under it.
  4. The editor is a sheet. No border, no focus-tint flash; a 68ch column of Source Serif 4 centred on white. Headings lose the H1 underline and gain space instead.
  5. Popovers stop being boxes of boxes. The format bar loses its grid of bordered boxes for borderless buttons on paper — teal fill for an active format, a teal ring for a mixed one; menus, dialogs and toasts share 10–12px radii, hairlines and a single shadow scale.
